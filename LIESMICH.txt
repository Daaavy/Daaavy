Analyte Comparison / Wertezuweisung
===================================

Starten (Windows)
  Doppelklick auf "Wertezuweisung_starten.bat".
  Beim ersten Start werden die Zusatzpakete (pdfplumber, reportlab) automatisch
  installiert. Voraussetzung: Python 3 ist installiert
  (https://www.python.org/downloads/, beim Installieren "Add python.exe to PATH" anhaken).

  Ohne Starter:  python Wertezuweisung.py
  (vorher einmalig: pip install -r requirements.txt)

Alle Dateien im selben Ordner belassen.

Ablauf
  1. Links "+ Hinzufügen…" -> Ringversuchs-PDFs auswählen (werden sofort eingelesen)
  2. Tab "Übersicht" prüfen, ggf. Labore links abwählen / Messungen einstellen
  3. Tab "Optimierung": Abdeckung einstellen, "Optimieren" (F5)
     Runs per Häkchen anpassen, rechts Proben / Referenzproben / Messtage eintragen
  4. "PDF exportieren…" (Strg+E) oder "Archivieren…"

Tastenkürzel
  Strg+S Speichern · Strg+O Öffnen · Strg+N Neue Planung · Strg+E Export
  Strg+L LOD-Werte anzeigen · F5 Optimieren · F1 Kurzanleitung

Bestehende .wz-Planungen können weiterhin geöffnet werden.
