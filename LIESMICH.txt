Analyte Comparison / Wertezuweisung
===================================

Starten (Windows)
  Doppelklick auf "Wertezuweisung_starten.bat".
  Beim ersten Start werden die Zusatzpakete (pdfplumber, reportlab, sv-ttk fuer
  das moderne Aussehen, tkinterdnd2 zum Hineinziehen von PDFs) automatisch
  installiert. Voraussetzung: Python 3 ist installiert
  (https://www.python.org/downloads/, beim Installieren "Add python.exe to PATH" anhaken).

  Ohne Starter:  python Wertezuweisung.py
  (vorher einmalig: pip install -r requirements.txt)

Alle Dateien im selben Ordner belassen.

Ablauf
  1. Links "Hinzufügen…" oder PDFs ins Fenster ziehen (werden sofort eingelesen)
  2. Tab "Übersicht" prüfen, ggf. Labore links abwählen / Messungen einstellen
  3. Tab "Optimierung": Abdeckung einstellen, "Optimieren" (F5)
     Runs per Häkchen anpassen, rechts Proben / Referenzproben / Messtage eintragen
  4. "PDF exportieren…" (Strg+E) oder "Archivieren…"

Tastenkürzel
  Strg+S Speichern · Strg+O Öffnen · Strg+N Neue Planung · Strg+E Export
  Strg+L LOD-Werte anzeigen · F5 Optimieren · F1 Kurzanleitung

Planungen speichern
  Strg+S speichert die Planung unter einem Namen im Reiter "Meine Planungen".
  Ab dann wird jede Änderung automatisch gespeichert (abschaltbar unter Datei).
  Die PDFs werden in die Planung kopiert - sie lässt sich also auch dann
  wieder öffnen, wenn die Original-PDFs verschoben oder gelöscht wurden.
  Im Reiter "Meine Planungen" (Strg+O): Öffnen, Duplizieren (z. B. als Vorlage
  für den nächsten Ringversuch), Umbenennen, Löschen, letztes PDF öffnen.
  Beim Start gibt es den Knopf "Weiter mit ..." für die zuletzt bearbeitete Planung.

  Gespeichert wird im Ordner "daten" neben dem Programm. Bei einem Update die
  neue ZIP einfach über den alten Ordner entpacken - "daten" bleibt erhalten.
  Gelöschte Planungen landen in "daten\papierkorb".

Alte .wz-Dateien: Datei -> "Planung aus Datei öffnen (.wz)...", dann Strg+S.
